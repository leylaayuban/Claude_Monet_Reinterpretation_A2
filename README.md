# Claude_Monet_Reinterpretation_A2

This code runs on Java in Processing. I have written my code using Processing version 4.5.6 but it works the same on the updated version 4.5.7.

Each file is a different tab section in my Processing sketch (e.g. design, lily, ellipse). 

Open a new sketch in Processing.

Copy each file of code into a new tab in your Processing sketch. 

To make a new tab, find the downwards facing triangle next to the sketch name. Press that and click 'New tab'. 

There should be three files/tabs in one sketch. Then you can run the code!

Open a new Processing sketch and follow the previous instructions to view the second artwork.
