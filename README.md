# Claude_Monet_Reinterpretation_A2

This code runs on Java in Processing. I have written it on the old version but it works the same on the updated version. (test this)
Each tab is a different tab section in my Processing sketch (e.g. spotify, lily, ellipse). 
Copy each section of code into a new tab in your processing sketch. To make a new tab, there should be a downwards facing triangle next to the sketch name. Press that and click 'New tab'.
Then just run the code!

Open a new Processing sketch and follow the same previous instructions to view the second artwork.
